# 🧺 Laundry Service Website

# Description
A simple laundry service landing page built using HTML and CSS. It provides a clean interface with service information and a booking button.

# Features
- Navigation bar with logo and menu links.
- Hero section with heading and description.
- Laundry-related image.
- Book a Service button.
- Layout using inline-block (without Flexbox).

# Technologies Used
- HTML5
- CSS3

# Project Structure
```text
Laundry-Website/
├── index.html
├── style.css
└── README.md
```

# How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.
